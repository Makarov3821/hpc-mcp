一项计算的数据流

A/B 输入→准备快照→上传校验→队列提交→状态追踪→下载暂存→核验并归位 A/B

项目模式可直接归位；未指定项目时按状态目录中的输出快照保存。调度状态与应用结果分开记录。

当前的持久化边界

  • 源码安装目录：Python 包与虚拟环境。
  • 配置 / 状态：显式 config、state-dir；README 引导放入 agent 数据目录。
  • 项目 A：原始输入、归位结果与项目模式同步暂存。
  • 集群 work_root：独立 run 目录、脚本、运行输出。

CLI 裸运行仍有相对路径默认值；安装引导中的绝对路径配置决定实际存放位置。

标准卸载闭环

预览占用→禁止新调用→清除注册 / 文件→核验残留

活动操作与版本引用明确阻止删除；中断可恢复，重复操作幂等。用户输入、计算结果和任务历史单独管理，不随插件删除。
